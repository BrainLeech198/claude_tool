# Claude 启动器

Windows 上的 Claude Code 图形启动器：左边挑模型，右边挑工作区，点一下就在
那个目录开个窗口跑 claude。单文件起家，现在拆成了一个包，目标是可以打包成
安装程序转发给别人。

## 现在能干什么

- **模型切换**：预设存成一个个 json，点一下覆盖 `~/.claude/settings.json`。
  内置国内四家 + 国外六家的 endpoint 和模型名，选一家贴个 key 就能用。
  带"测试"按钮——真打一次请求看通不通，连不上会把底层原因（超时/DNS/拒绝）
  一起显示出来。
- **工作区列表**：点一下就在那个目录开窗口；每行右侧显示"有没有交接文档"
  和"上次聊是多久以前"，可以直接改名、移除、上下挪（顺序就是 Ctrl+1~9 的顺序）。
  行首那个编号就是 Ctrl+数字按的那个号。
- **权限等级**：每次启动前自己选（每次都问 / 改文件不问 / 只规划 / 让模型批 /
  什么都不问），选过的按工作区记住。下拉里同时给出中文解释和 `acceptEdits`
  这类真名。
- **交接文档**：从这个启动器开出去的窗口，顶上"正在跑"那块会列出来，每条带
  一个"整理交接文档"。也可以挂 Stop hook 让它自动刷（会多花 token，默认关）。
- **独立窗口的控制**：在"正在跑"那行直接对那扇终端窗口动手——挪到启动器旁边、
  压到最上层、关掉。认的是窗口句柄（启动前后比对窗口名单拿到），所以窗口是
  用户的 Windows Terminal，照样能控制。
- **换模型时接着聊**：切换模型后，正在跑的会话逐个问"要不要接着聊"；答应的话
  依次做"写交接文档 → 关掉旧窗口 → 用新模型重开"，全程在主界面上有一块带
  进度条和已用秒数的区域。
- **内嵌终端**：可选，把 conhost 塞进主窗口，不用另开窗口。默认关。

## 跑起来

从源码跑（开发用，看得见报错）：

```bat
运行.bat
```

需要 Python 3（只用标准库，零第三方依赖）。

打完包之后给别人的是安装包，那边**不需要装 Python**：

```bat
build\打包.bat
```

出 `Output\ClaudeLauncher-<版本>-Setup.exe`。装的时候默认免管理员、装在自己账户
下；同一个目录也可以直接拷走双击运行，那份是免安装的。

## 目录

```
claude_tool/       源码包，见 设计说明.md 里的模块划分和依赖方向
设计说明.md        设计说明
build/             PyInstaller spec、Inno 脚本、图标、打包用的 bat
docs/              官网，GitHub Pages 就发这个目录，下载直链指 Gitee 发行版
```

官网发的是 `docs/` 这个目录的原因：GitHub Pages 的「Deploy from a branch」只认仓库
根 `/` 或 `/docs`，中间没有别的选项。发布源设成 `master` 分支 + `/docs` 目录即可，
不需要任何 Actions 或额外的 token 权限。

发一版要手动做的只有两件：把 `build\claude_tool.iss` 里的 `AppVersion` 改掉；在
Gitee 和 GitHub 上**各**建一个 tag 为 `<版本号>`（`0.1.0` 这样，不带 v）的发行版，
把 `Output\` 里那个 Setup.exe 传成附件。GitHub 那份就是官网卡片上「GitHub 下载」
那个入口指的地方——仓库代码是镜像过去的，**发行版附件不跟着镜像走**，得自己传。
其余都包在 `build\打包.bat` 里了，包括把这一版记进官网的版本清单。

用户数据在 `~/.claude_tool/`，跟 Claude Code 的配置分开，卸载时不该删。
详见 [设计说明.md](设计说明.md)。
