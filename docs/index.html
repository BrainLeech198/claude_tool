Claude 启动器

Windows / Linux 上的 Claude Code 图形启动器——左边挑模型，右边挑工作区， 点一下就在那个目录开个窗口跑 claude。

怎么装

两个平台都得先有 Claude Code 本身。没装的话启动器顶上会挂一条横幅，点「帮我装 claude」， 它照这台机器能走的装法一条条列出来，装的过程直接流在面板里。

Windows

  1. 下载上面那个 Setup.exe，双击。
  2. 装的时候默认免管理员，装在自己账户下（%LOCALAPPDATA%\Programs\claude_tool）。 想装成整机共用的，在向导里切换，或者命令行加 /ALLUSERS。
  3. 装完从开始菜单或桌面图标打开。第一次用先在左边加一个模型预设、填上 API key， 右边加个工作区目录，点一下就能开跑。
  4. 装完那个目录本身就是免安装的，整个拷到另一台机器上双击 claude_tool.exe 照样能跑。

安装包没做代码签名，Windows 的 SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。

Linux

  1. 下载上面 Linux 那格的 ClaudeLauncher-<版本号>-linux-x86_64.tar.gz。
  2. 解开放到一个你记得住的地方（下面这条里的 * 会自己匹配上版本号）：
    mkdir -p ~/apps && tar -xzf ClaudeLauncher-*-linux-x86_64.tar.gz -C ~/apps
    解开是一个 claude_tool/ 目录。里面的可执行文件本身就带着执行位，不用再 chmod。
  3. 跑起来：~/apps/claude_tool/claude_tool。第一次用先在左边加一个模型预设、 填上 API key，右边加一个工作区目录，点一下就能开跑。
  4. 想有个点着就能打开的入口，自己写个 .desktop 或者做个软链接就行——这包不带 安装器，放哪儿、怎么起都由你定。要挪走或者不要了，把那个目录删掉即可，用户数据在 ~/.claude_tool，不跟着走。

那包是 x86_64 的，解开放着就能跑，不用另装 Python——运行时都在包里。要有个图形桌面； 另外要有个终端模拟器，因为每个会话是开一扇终端窗口跑 claude：启动器会自己找 gnome-terminal / konsole / xterm 这一类的，都认不出来就看 $TERMINAL 指的是哪个。有两样是 Windows 版才有的：内嵌终端，以及「把窗口挪到启动器 旁边 / 压到最上层」（那边认的是窗口句柄，这边只记得自己起出去的那个进程号）。 「删交接文档」还要求机器上有 gio 或 trash-put，两个都没有时会报一句。

实话说一句：这个 Linux 包只在 WSL 里验过，还没在一台真 Linux 桌面的机器上解压跑过—— 缺个 so、字体不对这类事有可能出得来。碰上了到仓库提一句。
